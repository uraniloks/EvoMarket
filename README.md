# EvoMarket 0.1.14

**Автор:** [uraniloks](https://github.com/uraniloks)

EvoMarket — клиентский сканер торгового чата PrisonEvo для Minecraft, интегрированный как аддон EvoPlus. Он анализирует сообщения, доступные игровому клиенту, распознаёт объявления о покупке и продаже и распределяет предложения по категориям для удобного поиска.

> Неофициальный проект сообщества. EvoMarket не связан с DiamondWorld или EvoPlus и не одобрен их разработчиками.

## Скачать и обновить

- **Modrinth:** https://modrinth.com/mod/evomarket — основная площадка для загрузки версий после одобрения проекта.

## Возможности

- Читает сообщения чата и системные сообщения, доступные клиенту.
- Распознаёт торговые формулировки: `куплю`, `скупаю`, `продам`, `продаю` и похожие варианты.
- Разделяет предложения о покупке и продаже; несколько явных торговых действий в одном сообщении могут обрабатываться как отдельные предложения.
- Распределяет предложения по категориям, включая кейсы с рунами и питомцами, сокровища летучей мыши, орехи, лаки-блоки, опыт, косметику и игровую валюту.
- Распознаёт распространённые сокращения, варианты написания и регистр букв из торгового чата.
- Различает игровую валюту и ЛК (валюту личного кабинета), используемые как способы расчёта.
- Разбирает распространённые обозначения сумм и компактные записи курсов обмена.
- Сохраняет исходный текст сообщения, чтобы условия сделки были видны в контексте.
- Сохраняет локальную историю предложений (до 500 записей).
- Предоставляет сводный виджет, переключатель сканирования и очистку истории в настройках EvoPlus.
- Ничего не покупает и не продаёт автоматически: аддон только анализирует сообщения, которые получил клиент.

## Категории и распознаваемые сокращения

### Кейсы и сокровища

| Название | Сокращение |
|---|---|
| Кейс с рунами | `КР` |
| Редкий кейс с рунами | `РКР` |
| Кейс DP | `Кейс DP` |
| Кейс с питомцами | `КСП` |
| Золотой кейс с питомцами | `ЗКСП` |
| Адский кейс с рунами | `АКР` |
| Редкий адский кейс с рунами | `РАКР` |
| Эндер кейс с рунами | `ЭКР` |
| Редкий эндер кейс с рунами | `РЭКР` |
| Золотой кейс с рунами | `ЗКР` |
| Золотой адский кейс с рунами | `ЗАКР` |
| Золотой эндер кейс с рунами | `ЗЭКР` |
| Сокровища летучей мыши | `СЛМ` |
| Адские сокровища летучей мыши | `АСЛМ` |
| Эндер сокровища летучей мыши | `ЭСЛМ` |

Другие примеры нормализации:

- `зо`, «золотые орехи», «золотые орешки» → **ЗО**.
- `ро`, «редкие орехи», «редкие орешки» → **РО**.
- `лб`, «лаки блоки» → **ЛБ**; редкие и легендарные варианты → **РЛБ** и **ЛЛБ**.
- `АРКРы` / `АКРы` → нормализованное название категории.
- `кров` → **КР**.
- «доски с рыбалки» → **Доски**.
- «лег апгрейд», «лег апп», «лег апгрейда» → **Лег апгрейд**.
- «эндер опыт» и «эндер рыба» → **Энд опыт**.
- «ад рыба» и похожие обозначения адского опыта → **Адский опыт**.
- Катана, кометы, скин Вардена и другие косметические предложения → **Косметика**.
- «колбы!» → **Колбы**.

Список сокращений развивается по реальным примерам из чата; не все редкие варианты могут распознаваться безошибочно.

## Валюта и способы расчёта

- `т` / `T` используются для обозначения триллиона.
- `б` / `B` и `в` / `В` используются для обозначения биллиона согласно словарю сервера.
- Варианты записи курса вроде `20бк1` и `1тк10` обрабатываются как курс, а не как обычная фиксированная цена.
- Объявления продажи игровой валюты, например `Продам 10т за 1000 лк`, должны отображаться как **Игровая валюта**.
- ЛК и игровая валюта хранятся как отдельные способы расчёта. Продажа предмета за ЛК сама по себе не превращает предмет в категорию валюты.
- Формулировки вроде `оптом` и известные жаргонные варианты анализируются в контексте сообщения, чтобы не создавать случайные категории.

## Установка готового JAR

1. Скачай готовый `evomarket-*.jar` из [GitHub Releases](https://github.com/uraniloks/EvoMarket/releases) или с [Modrinth](https://modrinth.com/mod/evomarket), когда версия станет доступна.
2. Скопируй JAR в папку `mods` того же профиля Minecraft 26.2 с Fabric, где установлены EvoPlus и Fabric API.
3. Удали старые JAR-файлы EvoMarket, чтобы одновременно не загружалось несколько версий.
4. Запусти Minecraft. Окно аддона открывается сочетанием `Ctrl+M`.

## Сборка из исходников на Windows

1. Установи **JDK 25**: https://adoptium.net/temurin/releases/?version=25 (Windows x64, MSI).
2. Склонируй репозиторий или скачай его исходники.
3. Запусти `BUILD.bat`. При первой сборке скрипт скачает Gradle и зависимости, поэтому нужно подключение к интернету.
4. Дождись сообщения `BUILD SUCCESSFUL`.
5. Готовый JAR появится по пути `build/libs/evomarket-0.1.14.jar`.

В репозитории хранятся исходники; для скачивания готового JAR используй раздел Releases или страницу Modrinth.

## Известные ограничения

Торговый чат использует свободный текст, серверные сокращения и нестандартные обозначения цен. Некоторые предложения могут быть классифицированы неверно или отображаться с нераспознанной ценой. При сообщении об ошибке приложи оригинальное сообщение чата и ожидаемую категорию. Сообщения, полученные до запуска сканера, восстановить нельзя.

## Использование ИИ

ИИ-инструменты использовались для помощи при подготовке частей исходного кода, документации и тестов парсера, а также при создании графического ресурса. Проект находится в разработке, поэтому результаты распознавания нужно проверять на реальных сообщениях DiamondWorld.

## История изменений: 0.1.14

- Нормализация названий перед классификацией, чтобы начальные количества и конечная пунктуация не создавали дублирующиеся категории.
- `3кк ад рыбы` и похожие варианты относятся к **Адский опыт**.
- «эндер опыт» и «эндер рыбу» объединены в **Энд опыт**.
- Нижний/верхний регистр и варианты с количеством у `ЛЛБ`, `КР`, `КСП` и `ЛБ` приводятся к каноническим категориям.
- «скин Вардена» и «кометы» относятся к **Косметика**; `колбы!` нормализуется в **Колбы**.
- «очень много валки по курсу ...» относится к **Игровая валюта**, а не к отдельной категории «Очень много».
- Добавлена фильтрация шуток и сообщений, которые не являются торговыми предложениями.
- Добавлены регрессионные проверки на указанные примеры чата.
