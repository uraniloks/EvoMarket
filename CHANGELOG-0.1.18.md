# EvoMarket 0.1.18 — удобство рынка

## Новые возможности
- Добавлены избранные продавцы. Игрока можно добавить в избранное прямо из карточки объявления, а его предложения доступны во вкладке «Избранные».
- Добавлен игнор-лист продавцов. Объявления выбранных игроков скрываются внутри EvoMarket; обычный игровой чат не изменяется. Игрока можно вернуть из вкладки «Игнор-лист».
- Добавлена сортировка сначала по времени, по цене от меньшей к большей и от большей к меньшей.
- При сортировке по цене предложения группируются по способу расчёта — ЛК, игровая валюта и смешанный вариант не сравниваются напрямую.

## Улучшения интерфейса
- Размер окна и контролов приведён к более компактному виду, чтобы уменьшить визуальную перегруженность.
- Категории размещаются компактно — до четырёх в строке; выбранный пункт выделяется цветом.
- Кнопки сортировки находятся над списком объявлений.
- В карточках доступны действия с продавцом: добавить/убрать из избранного и игнорировать.
- Ограничено одновременное отображение 150 карточек, чтобы длинная история не перегружала интерфейс.

## Техническое
- Избранные и игнорируемые продавцы сохраняются локально между запусками.
- Добавлены регрессионные самотесты для списков продавцов и сортировки с разделением способов оплаты.

- Fixed scanner event registration by moving receive hooks to Fabric's standard client entrypoint; no version bump.

## Улучшение навигации (та же версия 0.1.18)
- Уменьшены ширина и высота основных кнопок, названия действий стали короче.
- Сетка категорий стала компактнее: четыре категории в строке, выбранная категория выделяется цветом.
- На страницах «Скрытые категории», «Избранные продавцы» и «Игнор-лист» добавлена явная кнопка «← К рынку».
- На странице скрытых категорий кнопки «Вернуть все» и «Вернуть» размещены компактно; выйти из этого раздела можно даже при пустом списке.
- Кнопки «Избранное» и «Игнор» в карточках объявлений стали компактнее.

## Compatibility and interface fixes

- Separated fixed navigation for “Все категории” and “Скрытые” from automatically detected item categories.
- Added optional ChatManager-Core / DiamondChat integration via the `MessageReceivedEvent` event bus, so trade messages are read before they are routed into separate chat windows.
- Kept ChatManager-Core optional through a reflection-based bridge; its classes and MegaEvents are not bundled into EvoMarket.
- Added a regression check for the ChatManager-Core message route.


## Дополнительная полировка интерфейса (та же версия 0.1.18)
- Добавлен разделитель между основными вкладками и сортировкой, чтобы убрать ощущение случайного пустого промежутка.
- Увеличен вертикальный отступ перед заголовком «Категории рынка».
- Добавлен разделитель между навигацией «Все категории / Скрытые» и содержимым выбранного раздела.
- На странице скрытых категорий добавлены дополнительные отступы вокруг заголовка и описания.
- Кнопки «Вернуть» выровнены по фиксированной колонке, независимо от длины названия категории.
- «Вернуть все» перемещена в отдельную строку справа и выделена красным полужирным текстом.

### Компактный HUD-виджет (исправление в рамках 0.1.18)
- Уменьшен размер сводного виджета с 250×48 до 200×36, чтобы не занимать лишнее место на экране.
- Убран технический счётчик полученных сообщений и добавленных объявлений из обычного HUD.
- Оставлены только общее количество объявлений и число покупок/продаж.
- Добавлен тонкий цветовой индикатор состояния сканера: зелёный — включён, красный — выключен.

## Исправление интерфейса (та же версия 0.1.18)
- Кнопки «Вернуть» в скрытых категориях и игнор-листе, а также «Убрать» в избранном выровнены по одной фиксированной колонке.
- Длинные и короткие ники больше не сдвигают кнопки по горизонтали.
- Ширина колонок и размеры кнопок приведены к одинаковым значениям для согласованного вида списков.
