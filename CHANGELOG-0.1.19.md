# EvoMarket 0.1.19 — поиск, удобство и исправления

## Новые возможности
- Добавлен поиск по предметам, игрокам и тексту объявлений.
- Добавлена постраничная навигация: до 20 предложений на странице.
- Добавлена адаптивная сетка категорий.
- Добавлены подсказки к элементам интерфейса.
- Добавлено копирование текста объявления.

## Исправления и улучшения
- Улучшена обработка закрытия, повторного открытия и переключения категорий.
- Исправлено смешивание предметов и валют между несколькими сделками в одном сообщении.
- Улучшено распознавание LC/ЛК, денежных сумм и торговых формулировок.
- Снижено число ложных торговых объявлений.
- Исправлена сортировка курсов и предложений со смешанными способами оплаты.
- Улучшены сохранение истории, обработка дубликатов и обновление списка предложений.
- Добавлены регрессионные самотесты для проверки парсера, сортировки, хранения данных и поведения интерфейса.

## Проверка
- В проект включены семь наборов автоматических self-test.
- Работа непосредственно в Minecraft должна быть проверена отдельно на клиенте с Minecraft 26.2, Fabric API и EvoPlus.
- Обычная Loom-сборка в среде аудита была ограничена окружением; JAR для этого выпуска был собран напрямую на Java 25. Не считайте это подтверждением полноценной проверки в игре.
